# 🛡️ القبة الحديدية — Iron Dome

لعبة متصفح ثنائية الأبعاد مبنية بمحرك **Phaser 3** — أقوى وأشهر مكتبة ألعاب HTML5 مفتوحة المصدر على GitHub.

أنت القائد في **مقر المراقبة والتحكم**: رادارك يرصد صواريخ العدو القادمة من منصات الإطلاق في الأعلى، ومهمتك حماية المدينة في الأسفل.

## طريقة اللعب

- **🎯 الاعتراض:** اضغط أي صاروخ قادم (أو قربه) — تنطلق صواريخ القبة الحديدية من أقرب بطارية وتلاحقه وتعترضه في السماء.
- **🚀 الضربة المضادة:** اضغط أي منصة إطلاق معادية لتدميرها بصاروخ بعيد المدى (+١٠٠ نقطة). تحتاج ٧ ثوانٍ لإعادة التجهيز، وتعود المنصة للعمل بعد ١٤ ثانية إن لم تنتهِ الموجة.
- **⌨️ مسافة (Space):** اعتراض تلقائي لأخطر صاروخ (الأقرب إلى المدينة).
- صواريخ مدرّعة (من الموجة ٢) تحتاج ضربتين وتُلحق ضرراً أكبر بالمدينة.
- كل موجة أسرع وأكثف من سابقتها، وبين الموجات تُصلَح المدينة جزئياً (+٥٪).

## التشغيل

افتح `index.html` في أي متصفح حديث — أو فعّل GitHub Pages من إعدادات المستودع (Settings → Pages → الفرع `main`) للعب برابط مباشر.

لا حاجة لأي تثبيت أو خادم: كل الرسومات مولّدة برمجياً داخل الكود، والمكتبة الوحيدة المحمّلة هي Phaser عبر CDN.

## التقنية

- Phaser 3.80 — فيزياء وحركة ومؤثرات
- JavaScript + HTML5 Canvas — تعمل على الهاتف والحاسوب
- لوحة مقر تحكم HTML حية: النقاط، الموجة، سلامة المدينة، وعدّاد الضربة المضادة
